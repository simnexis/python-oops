# Python Object-Oriented Programming (OOP)

This repository contains Python programs demonstrating the core concepts of
Object-Oriented Programming. Each folder focuses on a specific OOP principle
with simple and clear examples.

## Concepts Covered
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Purpose
- Understand OOP principles in Python
- Learn how to design reusable and modular code
- Practice real-world object-oriented concepts
